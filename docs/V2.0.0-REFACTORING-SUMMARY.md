## Breaking Changes Summary

### 1. Configuration Flattening

**Before:**
```yaml
agents:
  my_agent:
    ai_framework:
      provider: "azure_foundry"
```

**After:**
```yaml
agents:
  my_agent:
    provider: "azure_foundry"  # Direct property
```

**Impact:** Must update all `agent.config.yaml` files

---

### 2. Interface Rename

**Before:**
```csharp
public AgentFactory(
    IAIProjectClientFactory clientFactory,
    ...)
```

**After:**
```csharp
public AgentFactory(
    IProviderClientFactory clientFactory,
    ...)
```

**Impact:** Update constructor injection, DI registration, test mocks

---

### 3. Middleware Centralization

**Before:** Scattered middleware configuration across multiple options

**After:**
```yaml
agents:
  my_agent:
    middleware:
      open_telemetry:
        source: "my-agent"
      logging:
        enabled: true
      tool_calling:
        delegate: custom_handler
```

**Impact:** New configuration structure, centralized application order

## Technical Patterns Established

### Pattern 1: Centralized Middleware Application

```csharp
// Fixed application order
public static AIAgent ApplyMiddleware(
    this AIAgent agent,
    MiddlewareConfiguration? middleware)
{
    if (middleware is null) return agent;

    // Order: OpenTelemetry → Logging → ToolCalling
    if (middleware.OpenTelemetry is not null)
        agent.AddOpenTelemetryAgent(...);

    if (middleware.Logging is not null)
        agent.AddLoggingAgent(...);

    if (middleware.ToolCalling?.Delegate is not null)
        agent.ConfigureToolCalling(...);

    return agent;
}
```

### Pattern 2: Real ServiceProvider for DI Components

```csharp
// DON'T: Mock ILoggerFactory
var mockLogger = new Mock<ILoggerFactory>();

// DO: Create real ServiceProvider
var services = new ServiceCollection();
services.AddLogging();
var provider = services.BuildServiceProvider();
var loggerFactory = provider.GetRequiredService<ILoggerFactory>();
```

### Pattern 3: Real Instances for Sealed Types

```csharp
// DON'T: Mock sealed types
var mockOptions = new Mock<ChatClientAgentOptions>(); // NotSupportedException

// DO: Use real instances
var options = new ChatClientAgentOptions();
options.EnableJsonOutput = true;
Assert.True(options.EnableJsonOutput);
```

### Pattern 4: Integration Test Markers

```csharp
[Fact(Skip = "Requires real AIAgent with FunctionInvokingChatClient - needs integration test")]
public void Test_RequiringRealFramework()
{
    // Test body preserved for integration test implementation
}
```

## Migration Guide Quick Reference

### For SDK Users

1. **Update Configuration:**
   - Flatten `ai_framework.provider` → `provider`
   - Add `middleware` section if using OpenTelemetry/logging

2. **No Code Changes Required** (unless using internal APIs)

### For Contributors

1. **Update imports:**
   ```csharp
   // Before
   using Cyclotron.Maf.AgentSdk.Services.IAIProjectClientFactory;

   // After
   using Cyclotron.Maf.AgentSdk.Services.IProviderClientFactory;
   ```

2. **Update DI registration:**
   ```csharp
   // Before
   services.AddSingleton<IAIProjectClientFactory, ...>();

   // After
   services.AddSingleton<IProviderClientFactory, ...>();
   ```

3. **Add middleware configuration (optional):**
   ```csharp
   var middleware = new MiddlewareConfiguration
   {
       OpenTelemetry = new AgentOpenTelemetryOptions("my-source", null),
       Logging = new AgentLoggingOptions(loggerFactory, null)
   };
   ```
